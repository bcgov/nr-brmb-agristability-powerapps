Dashboard Data Modes: Query Reference

Reference for the two data modes in the Enrolments dashboard and which query work runs on the client versus server.

Mode Summary

Mode Primary Strategy Where Query Work Runs
Client-side Load selected year window dataset into browser, then filter/search/sort/page locally. Most query logic is browser-side after initial dataset fetch.
Server-side Request current page from Dataverse with filter/search/sort/order applied in query. Most query logic is Dataverse-side; browser renders returned page.

Query Matrix

Query Concern Client-side Mode Server-side Mode
Initial data load Client Fetches all records for selected years. Server Fetches one page of records for selected years.
Search Client In-memory string match on loaded rows. Server OData contains(vsi_name,...) in Dataverse query.
Quick filters / column filters / edit filters Client Applied in-memory. Server Converted to OData and sent as serverFilter.
Program year filtering Client Uses local year labels/values. Server Resolved to program year IDs and filtered by lookup ID.
Owner filtering Client Local match on owner display name. Server OData owner name conditions in query filter.
Sorting Client Browser sort on loaded rows. Server Dataverse orderBy from selected column and direction.
Pagination Client Slice array by page index. Server Dataverse paging with skip token traversal.
Info-box counts (New, Pending, Reminders) Client Count computed from loaded rows. Server Separate Dataverse count-style queries.
Total pages count Client Calculated from local filtered row count. Server Calculated from separate server total-results query.
