Enrollment App Quick Deploy Checklist

Repository: nr-brmb-agristability-powerapps/enrollment app

Updated: 2026-06-18

DEV Publish

  1. Open PowerShell in c:\agristability\nr-brmb-agristability-powerapps\enrollment app.
  2. Build the app.
  3. Push with npx power-apps push.
npm run build
npx power-apps push

TEST Migration + Publish

  1. Retarget project to TEST environment.
  2. Re-add required data sources if needed.
  3. Build the app.
  4. Push with npx power-apps push.
pac code init -n "enrollment app" -env "YOUR-TEST-ENV-ID"
pac code add-data-source -a "shared_office365users" -c "YOUR-CONNECTION-ID"
pac code add-data-source -a "shared_sql" -c "YOUR-CONNECTION-ID" -t "[dbo].[MobileDeviceInventory]" -d "SERVER,DATABASE"
npm run build
npx power-apps push

Post-Push Validation

  1. Landing page opens Enrolments by default with filters cleared.
  2. Dashboard nav opens Power BI in a new tab.
  3. Enrolments details/calculation/history navigation still works.
  4. Active Dataverse config row is populated for core and Power BI fields.
This checklist intentionally uses npx power-apps push (not pac code push).
